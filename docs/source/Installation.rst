Installation
''''''''''''''''''''

Requirements
^^^^^^^^^^^^

The package requires python ≥ 3.8 and these necessary dependencies:

   * CompRiskReg
   * formulaic
   * joblib
   * lifelines
   * matplotlib
   * numpy
   * pandas
   * prettytable
   * PyQt5
   * pytruncreg
   * scipy
   * seaborn
   * statsmodels
   * tqdm


All the dependencies needed by the pygformula are listed in the file
`"requirements.txt" <https://github.com/CausalInference/pygformula/blob/main/requirements.txt>`_ , users can
install them by:

.. code::

    pip install -r requirements.txt


Install pygformula
^^^^^^^^^^^^^^^^^^^^^^^^

Users can use the following command to install the pygformula package:

.. code::

  pip install pygformula
